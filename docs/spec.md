# Timetable 仕様書

実装のチェックリストは [todo.md](./todo.md)。

## 概要

曜日ごとの予定を、Google カレンダーの週表示に近いグリッド上で編集・閲覧する Android アプリ。

実カレンダーと違い、日付は進まない。画面は常に「月曜〜日曜」の枠として固定し、授業・シフト・ルーティンなどの繰り返し時間割として使う。特定の年月日には紐づけない。

配布・動作対象は Android のみ。Windows / macOS / Linux のデスクトップと iOS は対象外。

## 現状スコープ（v0.1）

- 週グリッド表示（左に時刻軸、横に月〜日）
- 予定の追加・編集・削除
- 予定は「曜日 + 開始時刻 + 終了時刻 + タイトル」で持つ
- 予定の重なりは許可する（見た目で重なって表示する）
- ローカル保存（アプリ再起動後も復元）

### 対象外（将来）

- 年月日から進むカレンダー（週送り・今日へジャンプなど）
- 月表示・日表示
- Google カレンダー連携・クラウド同期
- 通知・リマインダー
- 繰り返しルールの個別指定（毎週 / 隔週など）。v0.1 では枠そのものが「毎週同じ」
- 過去の時間割の履歴・バージョン切り替え（必要になったら追加する）
- デスクトップ（Windows / macOS / Linux）および iOS 向けの配布・最適化

## 画面構成

スマートフォンの縦画面を前提にする。週グリッドの描画方針は [tech-decisions/calendar-display.md](./tech-decisions/calendar-display.md) を参照。

- **週表示（メイン）**
  - 列: 月・火・水・木・金・土・日
  - 行: 時刻（表示は 6:00〜24:00、30 分刻み）
  - 予定は開始〜終了の矩形としてセル上に置く
- **予定の編集**
  - 空き時間をタップ（またはドラッグ）して新規作成
  - 既存の予定をタップして編集・削除
  - 入力項目: タイトル、曜日、開始時刻、終了時刻、メモ（任意）

## データモデル（案）

```
Event {
  id: string
  title: string
  dayOfWeek: 0..6   // 0 = 月曜 … 6 = 日曜
  startMinutes: number  // 0:00 からの分
  endMinutes: number
  note?: string
}
```

日付（年・月・日）は持たない。

## 制約

- 終了時刻は開始時刻より後であること
- タイトルは空不可
- 1 日の範囲は 0:00〜24:00。日をまたぐ予定は v0.1 では扱わない

## 技術スタック

- Tauri 2（Android） / React 19 / TypeScript / Vite
- パッケージマネージャ: pnpm
- ファイル I/O は Tauri コマンド `load_app_file` / `save_app_file`
- 予定はアプリデータディレクトリの `events.json` に JSON 配列で保存する。起動時に読み込み、追加・更新・削除のたびに全件を書き出す
- 読み込み時に壊れた行（タイトル空、終了 ≤ 開始など）は捨てる
